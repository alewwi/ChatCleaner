# 🧹 Chat Cleaner для SillyTavern

> **Большой чат снова летает: лишние свайпы и служебный код уходят, история остаётся.**

![SillyTavern](https://img.shields.io/badge/SillyTavern-1.18.0-blue) ![Version](https://img.shields.io/badge/version-1.0.0-green)

Чат на десятки мегабайт тормозит и роняет вкладку браузера. Почти весь его вес — это альтернативные свайпы, HTML-вёрстка и служебные блоки, которые давно не нужны. Chat Cleaner вычищает их из старых сообщений, а текст истории и реплики персонажей не трогает. Обычно чат становится легче в несколько раз.

---

## 🆕 Что нового

### _**v1.0.0**_

* Первый выпуск.
* Удаление лишних свайпов с сохранением выбранного.
* Очистка блоков по своим правилам в двух режимах: «Весь блок» и «Только код».
* Снятие HTML-оформления с сохранением текста.
* Защищённые блоки, которые не трогает ни одно правило.
* Бэкап перед очисткой: всегда, по запросу или никогда.

## ✨ Возможности

| Возможность | Описание |
|---|---|
| 🔀 **Лишние свайпы** | Остаётся только выбранный свайп. Свайпы последнего сообщения не трогаются. |
| 🧱 **Свои блоки** | Вписываете `<тег>` или `[МЕТКА]`, и расширение чистит эти блоки во всём чате. |
| ✂️ **Два режима** | «Весь блок» удаляет блок с содержимым. «Только код» убирает HTML, стили и скрипты, а текст оставляет. |

| 🛡️ **Защищённые блоки** | Метки, которые не заденет ни одно правило. |
| 🕐 **Свежие сообщения не трогаются** | Сами выбираете, сколько последних сообщений оставить как есть. |
| 💾 **Бэкап** | Копия чата перед очисткой: отдельным чатом или файлом. |
| 🔍 **Анализ** | Показывает, что будет удалено и каким станет размер, не меняя чат. |

## 🛠️ Установка

1. Откройте SillyTavern и нажмите кнопку **Extensions** (🧩).
2. Выберите **Install extension**.
3. Вставьте ссылку:

   ```
   https://github.com/alewwi/ChatCleaner
   ```

4. Нажмите **Install** (у администратора кнопка называется **Install just for me**) и обновите страницу.
5. В панели **Extensions** появится раздел **«Очистка чата»**.

<details>
<summary><b>Установка вручную</b></summary>

1. Скачайте репозиторий: **Code → Download ZIP**.
2. Распакуйте архив в `SillyTavern/data/default-user/extensions/` и переименуйте папку в `ChatCleaner`.
3. Перезапустите SillyTavern и обновите страницу.

> **⚠️ Внимание:** папка должна называться именно `ChatCleaner`, иначе панель настроек не загрузится.

</details>

> 💡 **Совет:** когда выходит новая версия, в **Extensions → Manage extensions** рядом с Chat Cleaner появляется кнопка **Update available**.

## 🚀 Быстрый старт

1. Откройте чат, который хотите почистить.
2. Впишите блоки для очистки и, если нужно, защищённые блоки.
3. Нажмите **«Анализ»**. Отчёт покажет, сколько свайпов и блоков уйдёт и каким станет размер. Чат при этом не меняется.
4. Нажмите **«Очистить текущий чат»** и подтвердите.

Расширение сохранит чат, сделает бэкап, почистит и перезагрузит чат.

> **⚠️ Внимание:** не запускайте очистку во время генерации. Расширение её заблокирует и попросит подождать.

## ⚙️ Настройки

### Основное

| Настройка | По умолчанию | Что делает |
|---|---|---|
| **Не трогать последних сообщений** | 10 | В этих сообщениях блоки и HTML остаются как есть, чтобы другие расширения видели свежие данные. |
| **Удалять лишние свайпы** | Вкл. | Оставляет выбранный свайп. Свайпы последнего сообщения не трогаются никогда. |
| **Снимать HTML-оформление** | Вкл. | Снимает стандартные HTML-теги со всего текста старых сообщений. Текст внутри остаётся. |
| **Защищённые блоки** | Пусто | Метки через запятую. Эти блоки не трогает ни одно правило и не задевает снятие HTML. |

### Бэкап

| Режим | Что происходит |
|---|---|
| **Делать всегда** | Бэкап перед каждой очисткой. Режим по умолчанию. |
| **Спрашивать каждый раз** | В окне подтверждения появляется галочка «Сделать бэкап». По умолчанию она включена. |
| **Не делать** | Бэкапа нет. Удалённое вернуть не получится. |

| Куда сохранять | Как выглядит |
|---|---|
| **Отдельным чатом** | Появится в «Управлении чатами» персонажа как `Имя чата - backup дата@время`. |
| **Файлом .jsonl** | Скачается через браузер. |

> 💡 **Совет:** чтобы откатиться, откройте бэкап из списка чатов персонажа и продолжайте в нём. Скачанный файл загружается кнопкой импорта чата.

> **⚠️ Внимание:** бэкап группового чата всегда скачивается файлом. Если бэкап не удался, очистка не начинается и чат остаётся нетронутым.

## 🧱 Блоки для очистки

Изначально список пустой. Каждое правило — это метка, режим, галочка «включено» и кнопка удаления. Новое правило добавляется кнопкой **«Добавить блок»**.

### Как записывать метки

| Вы вписываете | Что ищется |
|---|---|
| `<тег>` | От `<тег>` до парного `</тег>` с учётом вложенности. Самозакрывающийся `<тег/>` тоже. |
| `[МЕТКА]` | От `[МЕТКА]` до ближайшего `[/МЕТКА]`. Также `[МЕТКА: …]` и `[МЕТКА\| …]` до закрывающей скобки, с учётом вложенных скобок. |
| Слово без скобок | Ищется и как `<тег>`, и как `[МЕТКА]`. |

* Регистр букв не важен. Пробелы внутри квадратных скобок допустимы.
* Совпадение нужно полное: метка не задевает другую, которая начинается так же, но длиннее.
* Одиночная `[МЕТКА]` без пары не удаляется, потому что обычно это просто упоминание в тексте.
* Сломанный `<тег>` без пары в режиме «Весь блок» удаляется.

### Режимы

| Режим | Что происходит |
|---|---|
| ✂️ **Весь блок** | Блок удаляется вместе со всем содержимым. |
| 🧼 **Только код** | Блок и текст внутри остаются. Уходят HTML-теги, стили, скрипты, встроенные HTML-страницы, картинки и блоки ` ```код``` `. |

> 💡 **Совет:** если метка совпадает с защищённой, правило пропускается, а отчёт об этом предупредит.

## 🧼 Снятие HTML

Работает во всех старых сообщениях, а не только внутри блоков.

* Стандартные теги оформления снимаются, текст внутри остаётся.
* Стили, скрипты, векторная графика, фреймы и встроенные HTML-страницы удаляются целиком.
* Нестандартные теги не трогаются.
* Блоки ` ```код``` ` здесь не удаляются. Для них заведите правило в режиме «Только код».

После снятия тегов убираются лишние пустые строки и отступы в начале строк. Иначе markdown показал бы текст с отступом как блок кода.

## 🔍 Что именно меняется

<details>
<summary><b>Нажмите, чтобы развернуть</b></summary>

В каждом старом сообщении чистятся:

* видимый текст сообщения (`mes`) и оставшиеся свайпы;
* копии текста, которые хранят некоторые расширения: `extra.display_text`, `extra.reproRaw`, `extra.extblocks`, в том числе внутри данных свайпов.

SillyTavern показывает `display_text` вместо `mes`, поэтому без чистки копий очищенное сообщение выглядело бы по-старому.

Не меняются:

* метаданные чата: заметки автора, данные расширений, лорбуки;
* рассуждения модели (`extra.reasoning`);
* даты, имена и прочие служебные поля;
* последние сообщения в количестве, заданном в настройках.

Если указатель выбранного свайпа сломан и ведёт на несуществующий свайп, расширение находит свайп, совпадающий с видимым текстом. Если такого нет, свайпы сообщения остаются как есть, а отчёт об этом предупредит.

</details>

<details>
<summary><b>Проверка в node без SillyTavern</b></summary>

Скрипт ничего не записывает, только печатает отчёт. Правила и защищённые блоки впишите в `settings` так же, как в панели.

```js
// check.mjs — запуск: node check.mjs путь/к/чату.jsonl
import fs from 'node:fs';
import { cleanChat, DEFAULT_SETTINGS } from './cleaner.js';

const settings = {
    ...DEFAULT_SETTINGS,
    rules: [
        // { marker: '<тег>', mode: 'whole' },
        // { marker: '[МЕТКА]', mode: 'code' },
    ],
    protectedBlocks: '',
};

const lines = fs.readFileSync(process.argv[2], 'utf8').split('\n').filter(Boolean);
const chat = lines.slice(1).map(line => JSON.parse(line));
const stats = cleanChat(chat, settings, { apply: false });
console.log(stats);
```

Положите скрипт рядом с `cleaner.js`. В node 22 и новее он работает как есть. В более старых версиях переименуйте копию `cleaner.js` в `cleaner.mjs` и поправьте импорт.

</details>
