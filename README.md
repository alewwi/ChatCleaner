# Chat Cleaner — очистка чата

Расширение для SillyTavern, которое уменьшает большие чаты. Оно удаляет лишние свайпы и служебные блоки из старых сообщений: JSON-блоки HUD, HTML-вёрстку, мини-театры, комиксы и любые блоки, которые вы зададите сами. Текст истории и реплики персонажей остаются.

Чат на 60–70 МБ после очистки обычно весит в 3–5 раз меньше, и браузер перестаёт тормозить.

## Установка

Скопируйте папку `ChatCleaner` в `data/default-user/extensions/` и перезапустите SillyTavern. Настройки появятся в панели расширений (иконка кубиков) в разделе «Очистка чата».

## Как пользоваться

1. Откройте чат, который хотите почистить.
2. Нажмите **«Анализ»**. Появится отчёт: сколько свайпов и блоков будет удалено и каким станет размер. Чат при этом не меняется.
3. Нажмите **«Очистить текущий чат»**. Появится тот же отчёт с кнопками «Очистить» и «Отмена».
4. После подтверждения расширение сохранит чат, сделает бэкап, почистит и перезагрузит чат.

Не запускайте очистку во время генерации: расширение её заблокирует и попросит подождать.

## Настройки

### Не трогать последних сообщений

По умолчанию 10. В этих сообщениях блоки и HTML остаются как есть, чтобы HUD и другие расширения продолжали видеть свежие данные.

### Удалять лишние свайпы

Остаётся тот свайп, который сейчас выбран и виден в чате, поэтому текст истории не меняется. Свайпы последнего сообщения не трогаются никогда: его можно продолжать свайпать.

Иногда указатель выбранного свайпа ломается и ведёт на несуществующий свайп. Тогда расширение находит свайп, совпадающий с видимым текстом, и оставляет его. Если такого свайпа нет, сообщение пропускается, а в отчёте появляется предупреждение.

### Бэкап перед очисткой

| Режим | Что происходит |
|---|---|
| Делать всегда | Бэкап создаётся перед каждой очисткой. Это режим по умолчанию. |
| Спрашивать каждый раз | В окне подтверждения появляется галочка «Сделать бэкап перед очисткой». По умолчанию она включена. |
| Не делать | Бэкап не создаётся. Удалённое вернуть не получится. |

Бэкап копирует файл чата прямо с диска, после сохранения. Если бэкап не удался, очистка не начинается и чат остаётся нетронутым.

### Куда сохранять бэкап

- **Отдельным чатом в списке чатов персонажа.** Бэкап появится в «Управлении чатами» под именем вида `Имя чата - backup 2026-09-24@16h51m45s270ms`.
- **Скачать файлом .jsonl.** Файл скачается через браузер.

Бэкап группового чата всегда скачивается файлом.

**Как откатиться.** Откройте бэкап из списка чатов персонажа и продолжайте в нём. Скачанный файл можно загрузить кнопкой импорта чата.

### Блоки для очистки

Список правил. В каждом правиле есть метка блока, режим, галочка «включено» и кнопка удаления. По умолчанию заданы три правила:

| Метка | Режим | Что это |
|---|---|---|
| `[HUD]` | Весь блок | JSON-данные HUD |
| `<snow>` | Весь блок | Мини-театры с HTML, CSS и скриптами |
| `<comics>` | Весь блок | Комиксы с промптами картинок |

**Как записывать метки:**

| Вы вписываете | Что ищется |
|---|---|
| `<comics>` | От `<comics>` до парного `</comics>` с учётом вложенности. Самозакрывающийся `<comics/>` тоже. |
| `[DR_NOTES]` | От `[DR_NOTES]` до ближайшего `[/DR_NOTES]`. |
| `[TWEETS]` | Также блоки вида `[TWEETS: …]` и `[TWEETS\| …]` до закрывающей скобки, с учётом вложенных скобок. |
| `[snow hide]` | Метки с пробелами тоже работают. |
| `comics` | Слово без скобок ищется и как тег, и как метка в квадратных скобках. |

Регистр букв не важен. Метка `[HUD]` не задевает `[HUD_SUMMARY]`, а `<b>` не задевает `<body>`.

Одиночная метка без пары не удаляется. Например, если в вашем сообщении написано «включи `[HUD]` блок», эта фраза останется как есть. А вот сломанный HTML-тег без пары в режиме «Весь блок» удаляется.

**Режимы:**

- **Весь блок.** Блок удаляется вместе со всем содержимым.
- **Только код.** Сам блок и текст внутри остаются. Удаляются HTML-теги, `<style>`, `<script>`, встроенные HTML-страницы, картинки и блоки ` ```код``` `.

### Снимать HTML-оформление со всего остального текста

Включено по умолчанию. Работает во всех старых сообщениях, а не только внутри блоков.

- Теги оформления вроде `div`, `span`, `font`, `p`, `b` снимаются. Текст внутри остаётся, так что реплики из «пузырей» диалога сохраняются.
- `<style>`, `<script>`, `<svg>`, `<iframe>` и встроенные HTML-страницы удаляются целиком.
- Сюжетные и служебные теги не трогаются: `<time>`, `<prologue>`, `<plan>`, `<thinking>`, `<st-row>`, `<badges>` и любые другие нестандартные теги.
- Блоки ` ```код``` ` здесь не удаляются. Для них заведите правило в режиме «Только код».

После снятия тегов убираются лишние пустые строки и отступы в начале строк. Иначе markdown показал бы текст с отступом как блок кода.

### Защищённые блоки

По умолчанию `[HUD_SUMMARY]`. Можно вписать несколько меток через запятую, например `[HUD_SUMMARY], <plan>`.

Защищённые блоки не трогает ни одно правило и не задевает снятие HTML. Если такая же метка есть в списке блоков для очистки, это правило пропускается, а в отчёте появляется предупреждение.

## Что именно меняется

В каждом старом сообщении чистятся:

- видимый текст сообщения (`mes`) и оставшиеся свайпы;
- копии текста, которые хранят HUD и ExtBlocks: `extra.display_text`, `extra.reproRaw`, `extra.extblocks`, в том числе внутри данных свайпов.

SillyTavern показывает `display_text` вместо `mes`, поэтому без чистки копий очищенное сообщение выглядело бы по-старому.

Не меняются:

- метаданные чата: заметки автора, данные расширений, лорбуки;
- рассуждения модели (`extra.reasoning`);
- даты, имена и прочие служебные поля;
- последние сообщения в количестве, заданном в настройках.

## Файлы

| Файл | Что внутри |
|---|---|
| `cleaner.js` | Логика очистки. Не зависит от SillyTavern, её можно проверять в node на файлах `.jsonl`. |
| `index.js` | Подключение к SillyTavern: настройки, бэкап, запуск очистки. |
| `settings.html` | Панель настроек. |
| `style.css` | Стили панели и отчёта. |
| `manifest.json` | Описание расширения для SillyTavern. |

## Проверка в node

`cleaner.js` можно прогнать на выгруженном чате без SillyTavern. Скрипт ниже ничего не записывает, только печатает отчёт:

```js
// check.mjs — запуск: node check.mjs путь/к/чату.jsonl
import fs from 'node:fs';
import { cleanChat, DEFAULT_SETTINGS } from './cleaner.js';

const lines = fs.readFileSync(process.argv[2], 'utf8').split('\n').filter(Boolean);
const chat = lines.slice(1).map(line => JSON.parse(line));
const stats = cleanChat(chat, DEFAULT_SETTINGS, { apply: false });
console.log(stats);
```

Положите скрипт рядом с `cleaner.js`. В node 22 и новее он работает как есть. В более старых версиях переименуйте копию `cleaner.js` в `cleaner.mjs` и поправьте импорт.
